# 🧟 ZombieMusic

![Android](https://img.shields.io/badge/Android-App-3DDC84?logo=android\&logoColor=white)
![Estado](https://img.shields.io/badge/Estado-En%20desarrollo-brightgreen)

**ZombieMusic** es un reproductor de música para Android diseñado para ofrecer una experiencia **rápida, ligera y sin complicaciones**.
Escucha, descarga y organiza tu música en una interfaz moderna inspirada en las apps de música actuales.

> tu musica, tu estilo. 🎧🧟

---

# 🎵 Características

✔ **Reproductor rápido y ligero**
Disfruta tu música sin retrasos ni consumo excesivo de recursos.

✔ **Descarga de música**
Guarda tus canciones favoritas para escucharlas cuando quieras.

✔ **Modo offline**
Escucha tu música sin conexión a internet.

✔ **Playlists personalizadas**
Organiza tu biblioteca musical a tu manera.

✔ **Interfaz moderna**
Diseño limpio inspirado en reproductores actuales.

✔ **Optimizado para Android**
Funciona incluso en dispositivos modestos.

---

# 📥 Instalación

1. Descarga el **APK** desde la sección **Releases** del repositorio.
2. Activa **Instalar aplicaciones desconocidas** en tu dispositivo Android.
3. Instala el archivo APK.
4. ¡Disfruta tu música sin anuncios! 🎧

---

# ⚡ Tecnologías utilizadas

* Android Studio
* Java / Kotlin
* XML UI
* APIs de reproducción de audio

---

# 🚀 Objetivo del proyecto

ZombieMusic nació como un proyecto independiente con el objetivo de crear un reproductor de música **simple, eficiente y accesible**, eliminando lo innecesario y enfocándose en lo importante: **la música**.
